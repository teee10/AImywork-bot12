## 0. エグゼクティブサマリー

### 結論：需要はある。ただし「中小企業向けtoC営業コンサル」という切り口のままでは勝てない。

**事業の定義：toC商材を売っている中小企業に、営業のやり方を教える。**

| 論点 | 判定 | 根拠 |
|---|---|---|
| 市場は伸びているか | ◎ | 国内コンサル市場 2兆3,422億円（2024年度・前年比+17%）、BPO市場 5兆914億円（2024年度・+4.2%） |
| **需要はあるか** | **◎（ただし潜在需要）** | **「営業を教えてほしい」と探す社長はほぼいない＝顕在需要は弱い。だが「問い合わせは来るのに契約にならない」痛みは全社が持つ。売るのは"営業指導"ではなく"成約率"（→§2-0）** |
| 中小企業に課題があるか | ◎ | 人手不足倒産 214件（2025年・過去最多）。2026年版中小企業白書は「労働供給制約社会」「現状維持が最大のリスク」と明言＝**増員で解決する道が塞がれた** |
| toC中小企業に払う金があるか | △ | BtoC企業の価格転嫁力は低い（40%以上転嫁できた企業：BtoC 28.7% / BtoB 41.0%、人件費ではBtoC 16.9% / BtoB 28.7%）＝**フィーの原資が薄い**。ただし集客費は既に払っており、**予算の付け替えを狙える** |
| 競合は空いているか | ✕ | 船井総合研究所が「業種特化 × 月次支援 × 経営研究会」で実質制圧済み。汎用の「営業コンサル」はコモディティ |
| **ひとりで回せるか** | **△** | **設計次第。1対1の月次訪問モデルを選ぶと年商1,920万で頭打ち。コホート型なら4,800万〜1億が射程（§1）** |
| **単価は上げられるか** | **◎** | **顧客サイズ別価格の導入で、追加工数ゼロのまま平均単価+50〜90%。ただし1年目は不可（事例がないため）（→§5-3）** |
| **現実的にいくら狙えるか** | **○** | **3年目 年商4,830万／社長の取り分3,810万（到達確率35%）。船井総研の1人あたり売上1,600万の約3倍、診断士の上位5%相当。保守でも2,400万（→§8-1）** |

### 切り口の修正（4点）

1. **「営業コンサル」をやめ、1業種特化の「営業の型」パッケージにする**
   汎用の営業コンサルは差別化不能。業種を1つに絞り、その業界の言語で語れる状態を作る。
2. **月30〜100万円の顧問型を初手で狙わない**
   toC中小企業は利益率が薄い。「初期導入費＋低額サブスク＋補助金」で参入障壁を下げる。
3. **補助金を財源設計に組み込む**
   小規模事業者持続化補助金・IT導入補助金・よろず支援拠点の専門家派遣を前提に、顧客の実質負担を圧縮する。
4. **【最重要】1対1の訪問型を捨て、コホート（期別グループ）型にする**
   社長ひとりが稼働の全てである以上、**「1社に会う」ビジネスは構造的に詰む**。1回の稼働が6社に届く形にしなければ、需要があっても売上が伸びない。

### 基本戦略

**「すでに成功しているモデルを、1業種に絞り、ひとりで回る形に縮小して再現する」**

- 骨格の模倣元＝**船井総研**（業種特化 × 継続課金 × 同業コミュニティ）
- ただし同社の**「毎月訪問する月次支援」だけは模倫しない**。あれはコンサルタントを大量に抱えて初めて成立する人海戦術であり、ひとりでコピーすると自分の時間が即死する。
- 提供形態は**コホート型**（期間を区切って複数社を同時に進行）で置き換える。コホート型学習は修了率96%という報告もあり、成果面でも劣らない。

## 1. 制約条件：社長ひとり（この章が計画の芯）

### 1-1. 使える時間は「月100時間」しかない

| 用途 | 配分 | 時間/月 |
|---|---|---|
| **デリバリー**（顧客への価値提供） | 50% | **100時間** |
| 集客・営業（セミナー、商談、提携交渉） | 30% | 60時間 |
| コンテンツ制作・管理・経理 | 20% | 40時間 |
| **合計** | | **200時間** |

**この「デリバリー100時間」が事業の物理的な天井**であり、全ての設計はここから逆算する。

### 1-2. モデル別の天井シミュレーション

**【却下】1対1 月次訪問モデル**

| 項目 | 数値 |
|---|---|
| 1社あたり工数 | 8時間 + 移動4時間 = **12時間/月** |
| 100時間で対応できる社数 | **8社** |
| 月額単価 | 20万円 |
| **年商上限** | **約1,920万円** |

→ 8社で完全に埋まり、**それ以上1円も増えない**。しかも8社を維持したまま新規営業する時間が残らず、1社解約されるたびに売上が丸ごと消える。**このモデルは選んではいけない。**

**【採用】コホート型モデル**

| 項目 | 数値 |
|---|---|
| 1期の構成 | 6社を90日間、同時進行 |
| グループ講義 | 隔週2時間 × 6回 = 12時間 |
| 個別面談 | 1社1時間 × 6社 × 3ヶ月 = 18時間 |
| 商談解析・教材カスタマイズ | 30時間 |
| 準備・運営 | 20時間 |
| **1期あたり総工数** | **80時間（=約27時間/月）** |
| 同時進行 | 2期まで可能（54時間/月）＝デリバリー枠に収まる |
| **1期の売上（1年目・単価120万）** | 6社 × 120万 = **720万円** |
| **1期の売上（3年目・サイズ別価格）** | 平均230万 → **1,380万円**（→§5-3） |

→ **同じ100時間で、売上が2〜3倍になる。** これがひとりで戦う唯一の方法。
→ さらに**サイズ別価格を入れると、工数を1時間も増やさずに同じ1期が倍近くになる**（720万→1,380万）。ひとり事業では「社数を増やす」より「単価を上げる」ほうが常に正しい。

### 1-3. 「やらないこと」リスト（ひとりでは、これが戦略そのもの）

| やらないこと | 理由 |
|---|---|
| 訪問中心の月次顧問 | 移動時間が最大の原価。ひとりでは致命的 |
| 成果報酬型の営業代行 | 実働が発生する＝時間を売ることになる（前版で検討したが却下） |
| 複数業種の同時展開 | 業種特化の優位が消え、教材も使い回せない |
| 常駐・専属契約 | 1社に時間を占有される |
| 大企業・上場企業案件 | 稟議・報告資料の工数が重い。決裁者1人の中小企業だからこそ回る |
| 広告の大量運用 | 運用・改善に時間を取られる。提携とセミナーに集中する |
| **他社セミナーへの"参加"**（名刺交換目的） | 半日使って名刺10枚は1対1。**参加するなら"登壇"側に回る**（→§6-2） |
| プラットフォーム経由のスポット相談を主力にすること | 時間を売るモデルに戻ってしまう。**1年目のリサーチ用途に限定**（→§6-1） |
| コンサル業務の外注 | 品質＝自分。ここだけは外さない |

### 1-4. 外注するもの

動画編集・LP制作・資料デザイン・経理・事務。**自分の時間を1時間空けるために月5万払うのは常に正解**、という基準で判断する。

## 2. 市場環境（リサーチ結果）

### 2-0. 需要の「正体」——ここを間違えると売れない

**事業の定義：toC商材を売っている中小企業に、営業のやり方を教える。**

この需要は**2種類あり、強さが正反対**である。ここの見極めが事業の成否を決める。

| 需要の種類 | 強さ | 中身 |
|---|---|---|
| **顕在需要**（「営業を教えてほしい」と自分から探している） | **弱い** | 中小企業が自発的に検索するのは「集客」「チラシ」「ホームページ」であって「営業研修」ではない。営業教育に予算科目を持っている中小企業は少ない |
| **潜在需要**（「問い合わせは来るのに契約にならない」という痛み） | **非常に強い** | 集客費はすでに払っている。にもかかわらず受注が伸びない。この痛みは全社が抱えている |

**結論：「営業の教え方」を売ってはいけない。「成約率」を売る。**

- ✕「御社の営業を強化します」→ 何を買うのか分からない。後回しにされる
- ◎「同じ問い合わせ数のまま、受注を1.3倍にします」→ 既存の集客予算の投資対効果の話になり、**社長の関心事に直結する**

**この需要が実在すると言える根拠**

1. **業界内の成約率格差が2倍以上ある** — リフォーム業の一般的な成約率は3割前後とされる一方、成約率7〜8割（年間150件受注）の会社や「契約率92%」の営業が実在する。**同じ商材・同じ市場で2倍以上の差＝資質ではなく型の差であり、埋められる差**である
2. **増員では解けない構造になった** — 人手不足倒産214件（2025年・過去最多）、2026年版中小企業白書は「労働供給制約社会」「現状維持が最大のリスク」と明言。**人を増やして売上を作る道が塞がれた**＝1人あたり生産性を上げるしかない
3. **予算がすでに存在する** — 対象企業はチラシ・Web・イベントに支出済み。**新規予算の獲得ではなく、既存の集客予算からの付け替えを狙える**（新しい財布を開かせるより桁違いに易しい）
4. **同じ市場で先行者が稼いでいる** — 船井総研が「リフォーム事業で売上1.2億円」のモデルを持つ。**支払い実績が証明済みで、市場の存在を検証する必要すらない**

**逆に、需要面の弱点も正直に書く**

| 弱点 | 対策 |
|---|---|
| 「営業は根性・センス」と考える社長が一定数いる | 説得しない。**説得コストの低い層（＝すでに型化に関心がある層）だけを狙う**。ひとりで全市場を啓蒙するのは不可能 |
| 研修は効果測定しにくいと思われている | 成約率という**単一の数字**で語る。契約前にベースラインを測る |
| toC中小企業は原資が薄い（§2-2） | 補助金活用＋低額コミュニティを受け皿に |

### 2-1. 追い風

**① コンサル市場そのものが二桁成長**
- 国内コンサルティング市場：**2兆3,422億円（2024年度、前年比 +17%）**
- 経営コンサルティングサービス市場（グローバル）：2026年に5,535.6億USD、CAGR 12.35%の予測
- 供給（コンサル人材）より需要の増加が速い構造的な人材不足が市場成長を支えている

**② 営業アウトソース市場も堅調**
- 国内BPO市場：**5兆914億円（2024年度見込、前年比 +4.2%／矢野経済研究所）**
- 営業代行市場は2022年時点で約8,769億円、年平均成長率 +3.6%
- 拡大要因は「人材不足・働き方改革・DX」——本事業の顧客課題と完全に一致

**③ 人手不足が「営業の型化」需要を生む**
- **人手不足倒産 214件（2025年・過去最多）**
- 2026年版中小企業白書は「労働供給制約社会」を主題に据え、**「現状維持が最大のリスク」**という強いメッセージを出している
- → 中小企業の本音は「人を増やせないまま売上を上げたい」。これは増員ではなく**1人あたり生産性＝営業の型化**でしか解けない。本事業の存在理由はここにある。

**④ 顧客の課題と、自分の課題が同じ**
本事業自体が「ひとりで売上を上げる」挑戦であり、顧客も「人を増やせず売上を上げたい」。**自社の実践がそのまま教材になる**という、solo ならではの説得力を持てる。

### 2-2. 向かい風（正直に書く）

**① toC中小企業は原資が薄い**

価格転嫁の実態（40%以上転嫁できた企業の割合）：

| 転嫁対象 | BtoB | BtoC | 差 |
|---|---|---|---|
| 原材料費 | 41.0% | 28.7% | ▲12.3pt |
| 労務費・人件費 | 28.7% | 16.9% | ▲11.8pt |

toC事業者は値上げが通りにくく、利益が出にくい。**営業コンサルの相場価格（月30〜100万）をそのまま提示しても契約は取れない。**

**② 価格レンジの現実**

| 提供者タイプ | 月額相場 |
|---|---|
| 大手ファーム | 数百万円 |
| 独立系ファーム（顧問型） | 20〜30万円 |
| 一般的な定額制 | 30〜100万円 |
| **小規模コンサル会社** | **3〜5万円** |
| 時間制 | 1〜5万円/時間 |

中小企業が現実に払うゾーンは**月3〜30万円**。この帯で成立する原価構造を最初から設計する。

**③ 競合が強い**

船井総研は業種別・テーマ別・成長段階別にコンサルを展開し、「月次支援（毎月1回訪問・即時業績向上）」と「経営研究会（同業経営者が成功事例を学び合う会員制プラットフォーム）」を全国展開している。**正面から「中小企業の営業コンサル」を名乗るのは、この会社の主戦場に丸腰で入ることを意味する。**

**④ ひとりであること自体が最大のリスク**
コンサルなど自ら動いて売上が立つ業態は限界点が早く訪れ、拡大には「自らの時間を極力使わずに広げる」ことが必須とされる。また一人社長が年収1,000万を得るには**売上3,000万が必要**とされる。§1の設計はこの制約への回答である。

### 2-3. それでも空いている隙間

1. **船井総研がカバーしきれない業種・商圏が残る**（同社は業種を絞って深く入るため、未カバー領域が必ずある）
2. **年商1〜5億の小規模toC事業者は大手のターゲット外**——ここは単価が合わず大手が来ない。**ひとりだからこそ利益が出る価格帯**
3. **AI商談解析による低コスト型化**——従来「コンサルタントが同行して見る」しかなかった営業実態の可視化が、商談録音のAI解析で安く速くできる。**ひとりの時間を最も食う工程を機械に渡せる**＝ solo と相性が最高
4. **業界内の成約率格差が異常に大きい**＝改善余地を定量的に証明しやすい（§3）

## 3. ターゲット選定

### 3-1. 選定基準（ひとり前提で1項目追加）

| 軸 | なぜ重要か |
|---|---|
| ① 客単価が高い | 成果1件のインパクトが大きく、フィーの原資になる |
| ② 商談型の営業がある | 「型化」が効く（店頭・EC完結型は効かない） |
| ③ 事業者数が多い | 横展開できる＝1業種で食える |
| ④ 社内の成約率格差が大きい | Before/Afterを数字で示せる＝売りやすい |
| ⑤ 紹介・リピートが効く | CACが下がる |
| **⑥ 業界団体・FC本部・メーカーが存在する** | **ひとりで集客するには「1対Nで届く窓口」が必須** |

### 3-2. 候補業種の評価

| 業種 | 客単価 | 商談型 | 事業者数 | 格差 | 団体/FC | 総合 |
|---|---|---|---|---|---|---|
| **リフォーム（外装・水回り）** | ◎ 100〜300万 | ◎ 訪問商談 | ◎ 極めて多い | ◎ 非常に大 | ◎ FC・メーカー多数 | **◎ 第1候補** |
| 外構・エクステリア | ◎ | ◎ | ○ | ◎ | ○ | ○ 第2候補 |
| 自費診療クリニック（歯科・美容） | ◎ | ○ カウンセリング | ◎ | ◎ | ○ | ○ 第2候補 |
| 太陽光・蓄電池 | ◎ | ◎ | ○ | ○ | ○ | △ 規制リスク |
| 注文住宅 | ◎ | ◎ | ○ | ○ | ○ | △ 商談期間が長い |
| 保険代理店 | ○ | ◎ | ◎ | ◎ | ◎ | △ 既存プレイヤー飽和 |
| 学習塾 | △ | ○ | ◎ | ○ | ○ | △ 単価が低い |

### 3-3. 第1ターゲット：リフォーム事業者

**なぜリフォームか**

- **成約率の格差が異常に大きい** — 業界の一般的な成約率は3割前後と言われる一方、
  - 営業未経験でも成約率70%を実現するモデルが存在する
  - 取替系リフォームで**年間150件受注・成約率7〜8割**の会社が実在する
  - 「契約率92%」を掲げる現役営業もいる
  → **同じ商材で成約率が2倍以上違う＝個人の資質ではなく"型"の差**。提案トークがそのまま成立する。
- **勝ちパターンがすでに言語化されている** — ①徹底ヒアリングで潜在ニーズを引き出す ②共感ベースの提案 ③安心感を与える説明、という3ステップや、「キッチンが欲しいのではなく"料理を楽しみたい"」という便益翻訳トーク、紹介経由の高成約率など、**再現すべき型が公知**。ひとりで教材を作る負荷が小さい。
- **周辺の成功事例が豊富** — 相談会の開催で単価2.5倍、見学会による施工力PR等、打ち手のカタログがすでにある。
- 船井総研も「リフォーム事業立ち上げで売上1.2億円」のモデルを持つ＝**支払い実績が証明済み**。「需要があるか」を検証する必要すらない。
- **FC本部・建材メーカーが多数存在する**＝ひとりでも1対Nで集客できる（§6）。

**顧客像（ペルソナ）**

- 年商 1〜10億円、営業担当 3〜15名のリフォーム会社
- 社長がトップ営業で、社長の成約率だけ突出している
- 集客（チラシ・Web・イベント）にはすでに金を払っているが、**問い合わせは来るのに契約にならない**
- 採用してもすぐ辞める／育たない
- **決裁は社長1人＝商談1回で決まる**（ひとりで営業する上でこれは決定的に重要。稟議のある会社を相手にしてはいけない）

## 4. 模倣する成功モデル

### 4-1. 骨格：船井総研モデルの「ひとり版」

| 船井総研の構成要素 | 本事業での再現 | 判断 |
|---|---|---|
| 業種別の専門コンサルタント | リフォーム1業種に完全特化 | **模倣する** |
| 経営研究会（同業経営者の会員制コミュニティ） | 会員制コミュニティ（月4万） | **模倣する** |
| 成功事例の横展開 | ベンチマーク企業の型を会員に配布 | **模倣する** |
| セミナー → コンサル契約への導線 | オンラインセミナー → 診断 → 本契約 | **模倣する** |
| **月次支援（毎月1回訪問・1対1）** | **コホート型プログラムに置換** | **模倣しない**（人海戦術前提のため） |

**この構造の優れている点**（＝模倣する理由）
- 同業他社の成功事例が最強のコンテンツになり、**顧客が増えるほどコンテンツが濃くなる**（自分の労働を増やさずに価値が増える＝ solo に理想的）
- コミュニティが**低単価の入口**として機能し、そこから高単価プログラムへ引き上げられる
- 同業が集まるため**横比較の圧力**が働き、解約が止まる

### 4-2. 上乗せする差別化要素

| 要素 | 模倣元 | ひとりにとっての意味 |
|---|---|---|
| **コホート型（期別グループ）** | コホート学習（修了率96%の報告あり）、グループコンサル | **1回の稼働が6社に届く。最大のレバレッジ** |
| **AI商談解析** | amptalk等の商談解析SaaS | 最も時間を食う「商談の可視化」を機械化。**原価が下がる＝価格でも勝てる** |
| **動画教材化** | オンライン講座モデル | 1回作れば無限に使える。**説明の再演をゼロにする** |
| **補助金活用** | 中小企業支援施策 | 顧客の実質負担を圧縮し、価格の壁を越える |

## 5. サービス設計（ひとりで回る形）

### 5-1. 3階建て構造

```
【入口】 月1回のオンラインセミナー（録画を再利用／稼働2h）
            ↓
【Tier 1】営業実態診断           30万円（単発・サポート期間30日・工数8h）
          商談録音3件のAI解析＋改善レポート＋報告会
          ※訪問しない。録音を送ってもらう
          ※実行支援は含まない（→ 詳細は §5-2）
            ↓
【Tier 2】90日 営業型化プログラム  150〜320万円 ★主力
          ◆コホート制：6社を1期として同時進行
          ◆営業人数によるサイズ別価格（→ §5-3）
          ・オンライン集合講義 隔週2h × 6回
          ・動画教材（事前学習）
          ・個別面談 月1回 × 3ヶ月（オンライン）
          ・商談録音のAI解析フィードバック
          ・スクリプト／ヒアリングシートのテンプレ提供
          ※訪問はキックオフ1回のみ（任意）
            ↓
【Tier 3】会員制コミュニティ（2階層）
          ・スタンダード  4万円/月 …事例共有会＋テンプレ配布
          ・プレミアム   10万円/月 …＋個別相談枠 月30分（定員15社）
          ※これが継続収益の柱。会員が増えても稼働はほぼ増えない
            ↓
【Tier 4】幹部養成コース（3年目〜）  400万円/年・定員3社
          ※上位商品。単体の売上より「アンカー」としての価値が大きい
```

### 5-2. 有料診断の提供範囲とサポート期間

**サポート期間＝契約日から30日間。以降のサポートは一切含まない。**

ひとりで運営する以上、**期限を切らない商品を持った時点で事業が死ぬ**。「ちょっと相談いいですか」が無限に発生し、有料コホートの時間を食う。診断は明確に締める。

| 日程 | 内容 | 形式 | 工数 |
|---|---|---|---|
| Day 0 | キックオフヒアリング（現状・ベースライン測定） | オンライン60分 | 1.0h |
| Day 1–14 | 商談録音3件を提出 → AI解析＋手動レビュー | 非同期 | 3.0h |
| Day 15–20 | 診断レポート作成（強み・ボトルネック・改善優先順位） | — | 2.0h |
| Day 21 | **報告会**（レポート提出・処方箋の提示） | オンライン90分 | 1.5h |
| Day 22–30 | レポートに関する質問対応（チャット・メールのみ） | 非同期 | 0.5h |
| Day 31 | **サポート終了** | — | — |
| | | **合計** | **8.0h** |

**含むもの／含まないもの（契約書に明記する）**

| 含む | 含まない |
|---|---|
| 商談録音3件の解析 | 4件目以降の解析（追加5万/件） |
| 診断レポート＋報告会 | **スクリプトの作成・実装** |
| 改善の優先順位の提示 | **研修・ロープレの実施** |
| 30日間の質問対応 | 同行・訪問 |
| | 31日目以降のあらゆる対応 |

> **なぜ実行支援を含めないのか（設計上の要）**
> 診断に実行支援まで入れると「診断だけで十分」となり、**本命のコホートが売れなくなる**。診断は「病名と処方箋」まで。「治療」はコホートで行う。この線引きが Tier1→Tier2 の転換率50%を成立させる。

**申込特典（転換率を上げる仕掛け）**
診断料30万円は、**報告会から60日以内**にコホートへ申し込んだ場合、**全額を受講料に充当**する。実質無料になるため申込障壁が下がり、かつ60日の期限が意思決定を促す。

**診断の位置づけ**
診断の時間単価は3.75万円/hと低い。**これは意図的**で、診断は利益商品ではなく**導線商品**である。評価指標は時間単価ではなく**コホート転換率50%**。ただし無料にはしない——ひとり運営では冷やかしの応対コストが致命的になるため、**有料であること自体がフィルターとして機能する**。

### 5-3. 価格戦略：単価はどこまで上げられるか

**結論：上げられる。ただし「今すぐ一律に」ではなく、「実績と引き換えに、顧客サイズ別に」上げる。**

#### ① 最大の値上げ余地は「顧客サイズ別価格」にある

同じコホートに座っていても、**顧客が得る金額は会社規模で5倍違う**。均一価格は、大きい顧客から取り損ねているということ。

顧客が得る価値の試算（客単価150万・粗利率30% ＝ 1件あたり粗利45万、成約率+10pt改善時）：

| 営業人数 | 年間商談数 | 増える受注 | **顧客の年間粗利増** | 適正価格（価値の15〜25%） |
|---|---|---|---|---|
| 3〜5名 | 100件 | +10件 | **450万円** | **150万円** |
| 6〜10名 | 200件 | +20件 | **900万円** | **250万円** |
| 11〜15名 | 300件 | +30件 | **1,350万円** | **320万円** |

**提供工数は3社とも同じ**（同じ講義に座る）。つまり価格差はそのまま時間単価に乗る。

#### ② 値上げの手段（効果順）

| # | 手段 | 単価への効果 | 追加工数 | 判定 |
|---|---|---|---|---|
| 1 | **顧客サイズ別価格** | 大（平均+50〜90%） | **なし** | **最優先で導入** |
| 2 | **上位商品でアンカーを作る**（幹部養成コース400万） | 中（本命が安く見える） | 小 | 3年目に導入 |
| 3 | **コミュニティの階層化**（プレミアム10万） | 中 | 小（定員制で制御） | 2年目に導入 |
| 4 | **成果連動フィー**（改善分の粗利増の10%を6ヶ月） | 中〜大 | なし | 測定基準を契約書で厳密定義できるなら導入 |
| 5 | 補助金活用で「実質負担」を据え置いたまま定価を上げる | 大 | 小 | **採択は保証されないため、これ前提の価格設計はしない**（後述） |
| 6 | 期間延長版（6ヶ月・12ヶ月コース） | 中 | **大** | ひとりでは工数増が重い。**見送り** |

> **⚠️ 補助金を値上げの根拠にする際の注意**
> 小規模事業者持続化補助金・IT導入補助金が使えれば顧客の実質負担は下がるが、**採択は保証されない**。「補助金が通る前提の価格」を提示して不採択になると、顧客との信頼が一度で崩れる。**定価は補助金なしで成立する水準に置き、補助金は"通ればラッキー"として案内する。**

#### ③ 値上げロードマップ（実績と引き換えに上げる）

**1年目に高単価は売れない。事例がゼロだから。** 1年目は単価より「成約率+10ptを実証した事例」を優先する。

| | 1年目（事例0） | 2年目（事例8社） | 3年目（事例26社＋数字） |
|---|---|---|---|
| 診断 | 20万 | **30万** | 30万 |
| コホート 小（営業3〜5名） | **120万 均一** | 150万 | **180万** |
| コホート 中（6〜10名） | 〃 | 200万 | **250万** |
| コホート 大（11〜15名） | 〃 | 260万 | **320万** |
| コホート平均単価 | 120万 | **180万** | **230万** |
| コミュニティ | 4万/月 | 4万／10万の2階層 | 〃 |
| 幹部養成コース | — | — | **400万/年** |

**値上げの原資は「実績数字」**。1社目の Before/After（成約率30%→42% 等）が出た瞬間に、それが値上げのライセンスになる。逆に**数字が出ていないうちに上げると、確実に売れなくなる**。

#### ④ 値上げ後の時間単価

| Tier | 売上 | 工数 | 時間あたり単価 |
|---|---|---|---|
| Tier1 診断 | 30万 | 8h | 3.75万円/h（導線商品・意図的に低い） |
| Tier2 コホート（6社1期・3年目） | **1,380万** | 80h | **17.3万円/h** |
| Tier3 コミュニティ（45社） | 247万/月 | 15h/月 | **16.5万円/h** |
| Tier4 幹部養成（3社） | 1,200万/年 | 60h/年 | **20.0万円/h** |
| （参考）**1対1月次訪問** | 20万/月 | 12h | **1.7万円/h** |

**1対1訪問の時間単価は、値上げ後コホートの1/10。** ひとりで戦う以上、この表が全ての意思決定基準になる。

### 5-4. 補助金の組み込み

提案時に以下を併せて提示し、実質負担を下げる（申請支援もサービスに含める）：
- **小規模事業者持続化補助金** — 販路開拓の取り組みが対象
- **IT導入補助金** — CRM／商談解析ツール導入とセットで
- **よろず支援拠点／専門家派遣** — 無料相談窓口経由の紹介チャネルとしても機能

> ※補助金は年度ごとに要件・枠が変わる。実行時点の公募要領で必ず再確認すること。ここでの記載は制度の存在と活用方針の提示であり、採択を保証しない。

## 6. 集客（ひとりでやる以上、「1対N」しかやらない）

**「toC営業を教える会社が、自社の営業を型化できていない」は致命傷。自社が最初の実証事例になる。**

### 6-0. 集客チャネルを選ぶ唯一の基準

ひとりの集客時間は**月60時間**しかない。だから判断基準は「効きそうか」ではなく、**「1回の稼働で何社に届くか」**の一点だけである。

| 型 | 1回の稼働で届く数 | 判定 |
|---|---|---|
| **1対N**（登壇・提携・寄稿） | 数十社 | **ここに全額投下する** |
| 1対1（名刺交換・テレアポ・訪問） | 1社 | **原則やらない** |

**この基準に照らすと、「他社セミナーに参加して名刺交換する」は1対1なので不採用**になる。ただし**"参加"を"登壇"に変えるだけで、同じセミナーが最強のチャネルに変わる**（→§6-2）。

### 6-1. 検討した2案の評価

#### 案A：プラットフォーム集客 → **メインにはならない。1年目の「リサーチ用途」に限定する**

ビザスク、比較ビズ、顧問マッチング系などのプラットフォーム。結論は**不採用（ただし別用途で使う）**。

| 問題 | 中身 |
|---|---|
| **① そこにターゲットがいない**（決定的） | ビザスクの依頼者は900社の法人で、大手・IT・都市部が中心。**年商1〜10億の地方のリフォーム会社の社長が、営業コンサルを探してプラットフォームに登録するか？　しない。** §2-0で確認したとおり、この事業の需要は**潜在需要**である。プラットフォームは「探している人」を捕まえる仕組みなので、**顕在需要が弱い商材とは構造的に噛み合わない** |
| **② 売る形が違う** | ビザスクの謝礼相場は**1時間3万円**（フルサポートでも8〜9万円）。これは§1で却下した**「時間を売るモデル」そのもの**。コホートの時間単価（9〜17万円）に遠く及ばず、しかも**積み上がらない**（やめた瞬間ゼロ） |
| **③ 12万人の中の1人** | 国内登録アドバイザーは12万人。実績・差別化のない1年目は埋もれる |
| **④ 相見積もり型は価格競争** | 比較ビズ等は複数社比較が前提。事例ゼロの1年目に価格勝負を挑むのは不利 |

> **ただし、1年目に限れば使い道が2つある。**
> **(1) リサーチ手段として** — Phase 0の「リフォーム会社20社ヒアリング」は、実は最難関の工程（そもそもアポが取れない）。プラットフォームに**相談を受ける側として登録**しておけば、**業界の生の悩みを、報酬をもらいながら聞ける**。これは極めて効率が良い。
> **(2) 練習台として** — スポット相談で場数を踏み、トークと仮説を磨く。
> **位置づけは「集客チャネル」ではなく「リサーチと練習の場」。3〜6ヶ月で卒業する。**

#### 案B：セミナーに参加して人脈から営業 → **"参加"では厳しい。"登壇"に変える**

| 問題 | 中身 |
|---|---|
| **① 時間対効果が悪い** | 1回参加で半日（4h）。名刺10枚 → アポ1〜2件 → 成約0〜1件。**月60時間の1/4を使って成果1件では、ひとりでは持たない** |
| **② 決裁者に会えない** | 参加者は担当者・管理職が中心。§3-3で定めた「社長ひとりで決められる会社」に当たる確率が低い |
| **③ 同業だらけ問題** | 経営セミナーの参加者には、コンサル・士業・保険・人材・広告の営業が大量にいる。**売りたい人同士が名刺交換する場**になりやすい |
| **④【最大】立場が"格下"になる** | 同じ部屋にいても、**名刺を配る人**と**壇上で話す人**では、信頼の初期値がまったく違う。しかも**「営業を教える人」が自分は名刺配りをしている**という姿は、商品そのものと矛盾する |

### 6-2. 修正案：セミナーは「参加」ではなく「登壇」する

**同じセミナーでも、立ち位置を変えるだけで全部ひっくり返る。**

| | 参加する（案B） | **登壇する（修正案）** |
|---|---|---|
| 届く人数 | 名刺交換10人 | **会場全員（数十社）** |
| 立場 | 売り込む側 | **教える側＝先生** |
| 集客の手間 | 全部自分 | **主催者がやってくれる** |
| 追いかけ方 | こちらから追う | **向こうから来る** |
| 1回の稼働 | 4h＋その後の追客 | **2h＋準備** |
| §6-0の基準 | 1対1 → ✕ | **1対N → ◎** |

### 6-3. 登壇機会をどこで作るか（優先度順）

| 優先 | 場 | なぜ効くか |
|---|---|---|
| **★★★ 1位** | **建材メーカー・FC本部の加盟店会** | 加盟店の売上増は主催者側の利益にも直結するため、話を聞いてもらえる。**1提携でコホート1期分が埋まる** |
| **★★★ 2位** | **地銀・信金の取引先向けセミナー**（新規追加） | 下記のとおり、条件が揃いすぎている |
| **★★ 3位** | 商工会議所・商工会／よろず支援拠点の専門家登録 | 地方ほど講師が不足している。無料〜謝礼あり。受動的に紹介も来る |
| **★★ 4位** | 自社オンラインセミナー（月1回） | 唯一自分で完全にコントロールできるチャネル。録画・資料を使い回せる |
| **★ 5位** | 業界紙（リフォーム産業新聞等）への寄稿 | 権威付け。**寄稿がそのまま登壇依頼の呼び水になる** |

### 6-4. 【最有力の新チャネル】地銀・信用金庫ルート

**この事業にとって、条件が揃いすぎている。**

| 理由 | 中身 |
|---|---|
| **① 銀行側に強い動機がある** | 地域金融機関は取引先の**「本業支援」**を求められており、ビジネスマッチングや経営相談を制度として持っている。**取引先の売上が伸びることは銀行の利益そのもの** |
| **② 実際に外部講師を探している**（決定的な証拠） | 船井総研が地銀・信金向けに**「外部専門家を上手に活用！事例に学ぶこれからの本業支援！」**というセミナーを開催している。**＝金融機関が外部専門家を求める市場が実在することの証明**であり、同時に**このルートを勝ち組がすでに使っているという証拠**でもある |
| **③ 紹介の信頼度が桁違い** | 「取引銀行からの紹介」は、飛び込みや広告とは断られ方がまったく違う。**信用をゼロから作らなくていい** |
| **④ 集客工数がゼロになる** | 銀行が取引先を集めてくれる。**ひとりの最大のボトルネックを、他人の営業力で解決できる** |

**攻め方（注意点込み）**

- **入口は支店ではなく本部。**「地域支援部」「ソリューション営業部」「法人推進部」など、本業支援を担う部署にあたる
- **最初は無償の講師として入る。** 金融機関は「特定業者への利益供与」を嫌うため、初回から営業色を出すと二度と呼ばれない
- **時間がかかる（半年〜1年）。だから今すぐ始める。** 1年目の売上には間に合わなくても、2〜3年目の土台になる
- 持っていく手土産は**「御行の取引先の売上が上がる話」**であって、自分の商品説明ではない

### 6-5. 時間配分（月60時間の使い道）

| 用途 | 1年目 | 3年目 |
|---|---|---|
| 提携交渉（メーカー・FC本部・**金融機関**） | 30h | 35h |
| 自社セミナーの実施・準備 | 15h | 15h |
| 寄稿・コンテンツ制作 | 10h | 10h |
| プラットフォーム（リサーチ用途・**1年目のみ**） | 5h | 0h |
| **合計** | **60h** | **60h** |

### 6-6. やらない集客

テレアポ、飛び込み、大量の広告運用、SNSの毎日投稿、**そして他社セミナーへの"参加"**。**いずれも1対1で、時間を無限に吸う。**

## 7. 収支計画（3ヵ年・ひとり前提・仮説）

### 7-2. 3シナリオ（提携が決まるかどうかで、ほぼ決まる）

売上は「値上げが通るか」「提携が決まるか」の2変数でほぼ決まる。単一の数字を信じず、レンジで持つ。

ひとり事業なので、比較は**「社長の取り分（＝売上 − 経費。役員報酬と利益の合計）」**で行う。

| | **保守ケース** | **標準ケース ★KGI** | **上振れケース** |

| 前提 | 値上げ通らず（120万据置）<br>提携1社／充足4社／年2期 | 値上げ成功<br>提携3社／充足5社／年3期 | 値上げ全通<br>提携6社／充足6社／年4期<br>＋幹部養成・ライセンス |
| 3年目 売上 | **約2,400万** | **約4,830万** | **約1億1,010万** |
| 経費 | 約700万 | 約1,020万 | 約2,000万 |
| **3年目 社長の取り分** | **約1,700万** | **約3,810万** | **約9,010万** |
| デリバリー稼働 | 月28h | 月41h | 月64h |
| **到達確率（主観）** | **約70%** | **約35%** | **約10%** |
| 判定 | ひとりの生活としては十分成立 | **目標シナリオ** | 上限。これ以上は人を雇う判断へ |

**保守ケースでも事業として成立する**——ここが重要。ひとりで固定費が軽いため、下振れても潰れない。**上振れを狙える下振れ耐性がある**のが solo の構造的な強み。

## 8. KGI / KPI

### 8-1. 【前提】KGIの現実性検証 ——実在データとの突き合わせ

KGIを決める前に、**「この手の事業は、現実にいくらまで行くのか」を実在データで確かめる。** 自分の積み上げ計算だけを信じると、机上の数字になる。

#### ベンチマーク①　業界最強企業の「1人あたり売上」

| 項目 | 数値 |
|---|---|
| 船井総研HD 売上高（2025年9月期） | **245億4,000万円**（前年比110.3%） |
| グループ従業員数（2024年12月末） | **1,535名** |
| **1人あたり売上** | **約1,600万円** |
| 純利益 | 25億8,500万円（純利益率 **10.5%**） |

**この業界のトップランナーですら、1人あたり売上は1,600万円。** 中小企業向けコンサルの「1人が生み出せる金額」の現実的な基準がこれである。

#### ベンチマーク②　中小企業向けコンサル従事者の年収分布

中小企業診断協会「活動状況アンケート」（コンサル業務年100日以上が対象）：

| 年収帯 | 割合 |
|---|---|
| 最多ゾーン | **501〜800万円** |
| 800万円以下 | **約50%** |
| 1,000万円以上 | 約34% |
| **3,001万円以上** | **約5%** |

#### ベンチマーク③　フリーランス／独立コンサルの実態

| 項目 | 数値 |
|---|---|
| フリーランス平均所得 | 470〜480万円 |
| 年収400万円以下 | **約半数**（200〜400万未満だけで27.9%） |
| 年収1,000万円以上 | 約1割 |
| フリーコンサル（常駐型）の年商 | 月単価150〜200万 → **年1,800〜2,400万** |
| 個人企業の平均年商 | **1,418万円**（法人企業は3億1,092万円） |

> フリーコンサル常駐型の年2,400万は、**「自分の時間を売り切った場合の上限」**とみなせる。ここが「時間を売るモデル」の天井である。

#### 検証：当初計画の「3年目1.1億」は妥当か

**結論：不可能ではないが、"標準ケース"に置いたのは誤りだった。上振れケースに格下げする。**

| 比較軸 | 当初計画 1.1億の位置 |
|---|---|
| 船井総研の1人あたり売上（1,600万）比 | **6.9倍** |
| 同・間接部門を除いた稼働コンサル推定（約3,200万）比 | **3.4倍** |
| 診断士の上位5%ライン（3,001万円）比 | 大幅超過 |
| 時間を売るモデルの天井（2,400万）比 | **4.6倍** |

#### では、なぜ「1,600万を超えること自体」は合理的なのか

1.1億は行き過ぎだが、**船井総研の1人あたり1,600万を上回ること自体は、構造的に説明がつく**。

| 理由 | 内容 |
|---|---|
| **背負う固定費が違う** | 船井総研は間接部門・オフィス・採用育成・上場維持コストを背負う。ひとりは背負わない |
| **提供形態が違う** | 船井総研の主力は月次支援（1対1訪問）＝1人あたり売上が構造的に頭打ちになる形。**コホート型はその制約を外している** |
| **ストックの比率が違う** | 会員制サブスクは会員が増えても稼働がほぼ増えない |

つまり**方向性は正しい。倍率の見積もりが甘かった。**

#### 【重要】ひとり事業の本当の強みは「売上規模」ではなく「利益率」

| | 船井総研HD | 本事業（ひとり） |
|---|---|---|
| 売上 | 245億円 | 4,800万円 |
| 純利益率 | 10.5% | **利益率 60%以上**（人件費・オフィス・採用コストがゼロのため） |
| 社長個人の取り分 | 給与のみ | **利益のほぼ全額** |

**年商4,800万・取り分3,800万のひとり社長は、年商5億・利益5,000万の会社の社長より、手取りで勝つ可能性が高い。**
→ **規模を追う必要がない。**これがこの事業形態を選ぶ最大の理由であり、KGIを売上で語ってはいけない理由でもある。

### 8-2. KGI（3年目の到達目標・改訂版）

#### 3つのケースと到達確率

売上ではなく**「社長の取り分（＝売上 − 経費。役員報酬と利益の合計）」**で見る。ひとり事業では、これが唯一意味のある数字である。

| ケース | 年商 | 経費 | **社長の取り分** | 到達確率（主観） | 根拠となる実在データ |
|---|---|---|---|---|---|
| **保守** | 2,400万 | 700万 | **1,700万** | **約70%** | フリーコンサル常駐型の年商レンジと同等。**時間を売っても届く水準**なので下限として堅い |
| **標準 ★KGI** | **4,830万** | **1,020万** | **3,810万** | **約35%** | 船井総研の1人あたり売上の**約3倍**。診断士の上位5%（3,001万超）に相当 |
| **上振れ** | 1億1,010万 | 2,000万 | 9,010万 | **約10%** | 提携6社が全て決まり、値上げも全て通った場合のフルポテンシャル |

> **当初計画からの変更点：** 標準ケースを1億1,010万 → **4,830万**に引き下げた。1.1億は船井総研の1人あたり売上の6.9倍にあたり、標準として置くには楽観が過ぎる。**1.1億は「狙う価値のある上振れ」として残すが、意思決定は4,830万を基準に行う。**

#### KGIは4つセットで持つ

ひとり事業のKGIは**売上だけにしてはいけない**。稼働時間を無視すれば売上はいくらでも作れてしまい、その先にあるのは燃え尽きだからである。

| # | KGI | 3年目 目標 | なぜこれか |
|---|---|---|---|
| 1 | **社長の取り分** | **3,810万円** | 売上より本質的。ひとり事業で唯一意味のある収益指標 |
| 2 | **年商** | **4,830万円** | 参考値。**これ自体を目標にしない**（虚栄の指標になりやすい） |
| 3 | **デリバリー稼働** | **月100時間以内**（見込41h） | **これを外すと1・2を達成しても事業が壊れる** |
| 4 | **顧客の成約率改善達成率** | **顧客の80%で+10pt以上** | 事業の存在理由。これが崩れたら他の3つは続かない |

**KGI 1〜3は自分の話、KGI 4は顧客の話。4が先で、1〜3は結果である。**

#### 損益分岐点：どこを超えれば「食える」か

| 指標 | 数値 |
|---|---|
| 年間固定費（役員報酬を除く） | 約460万円（1年目） |
| **固定費を回収するのに必要な受注** | **コホート4社**（120万×4＝480万） |
| 生活費込みで成立するライン | **コホート8社 ＋ コミュニティ15社** |

**コホート1期（6社）を埋めるだけで、1年目の固定費は回収できる。** 参入リスクが小さいのは、この構造による。

### 8-3. KPIツリー（3年目・標準ケースの分解）

```
【KGI】社長の取り分 3,810万円　（年商 4,830万 − 経費 1,020万）
│
├─ コホート売上 3,000万 ＝ 期数 × 定員 × 充足率 × 平均単価
│   ├ 期数           3期/年
│   ├ 定員           6社/期
│   ├ 充足率         83%（5社／最低ライン4社）
│   └ 平均単価       200万円 ← サイズ別価格のミックスで決まる
│
├─ コミュニティ売上 1,350万 ＝ 平均会員数 × 平均月額 × 12
│   ├ 平均会員数     25社
│   │   ├ コホート→コミュニティ転換率  60%
│   │   └ 月次解約率                 3%以下 ★
│   └ 平均月額       4.5万円（スタンダード4万／プレミアム10万のミックス）
│
└─ 診断売上 480万 ＝ 16社 × 30万
```

> **上振れケース（1億1,010万）との違いは「期数」と「提携先の数」だけ**である。3期→4期、提携3社→6社、充足5社→6社。**商品も工数構造も変えずに倍以上になる**——だからこそ上振れは狙う価値があるが、標準に置いてはいけない。

### 8-4. ファネルKPI（コホート15社をどう埋めるか）

```
セミナー開催 12回/年
      ↓ 10社/回
セミナー参加 120社
      ↓ 有効リード化 30%
有効リード 36社
      ↓ 診断化 44%
有料診断 16社 ────────┐
      ↓ 転換 50%      │
自社集客経由 8社       │
                      │＋ 提携経由 7社（提携先3社 × 2〜3社/年）
                      ↓
            【コホート 15社】
```

**律速はセミナー集客ではなく「提携先の数」。** 自社集客だけでコホート15社を埋めようとすると、セミナー参加が年225社必要になり、ひとりの集客工数では不可能。**提携で半分を埋める前提が崩れると、この計画は成立しない**——ここが計画最大の急所であり、§9の検証で最初に潰すべき点である。

**そして、標準ケース（提携3社）と上振れケース（提携6社）を分けるのも、この1点である。** 売上を2倍にする方法は「もっと働く」ではなく「提携をあと3社決める」。

| 区分 | 指標 | 1年目 | 2年目 | 3年目 |
|---|---|---|---|---|
| **集客** | **提携先の数** ★最重要 | 1社 | 2社 | **3社** |
| | セミナー開催 | 6回 | 12回 | 12回 |
| | セミナー参加社数/回 | 6社 | 8社 | 10社 |
| **転換** | セミナー→有効リード | 25% | 30% | 30% |
| | 診断→コホート | 40% | 50% | 50% |
| | コホート→コミュニティ | 50% | 60% | 60% |
| **単価** | コホート平均単価 | 120万 | 170万 | **200万** |
| | コホート期数×充足 | 2期×4社 | 2期×5社 | **3期×5社** |
| **継続** | コミュニティ月次解約率 | — | 5%以下 | **3%以下** |
| | 顧客あたりLTV | 200万 | 300万 | **400万** |
| **成果** | 顧客の成約率改善 | +8pt | +10pt | **+10pt** |
| | 成果達成した顧客の割合 | 50% | 70% | **80%** |
| | 顧客の受注単価改善 | — | +10% | **+15%** |
| **収益** | 年商 | 1,350万 | 2,800万 | **4,830万** |

**「売上/デリバリー時間」が、この事業の健康診断の数値。** 売上が伸びてもこの数字が伸びていなければ、単に働く時間が増えているだけであり、**ひとり事業としては失敗している**。

> **3年目でも稼働は月41時間。** 上限100時間に対して6割の余裕がある。**この余白こそが上振れケース（1.1億）への伸びしろ**であり、同時に「病気や想定外があっても倒れない」保険でもある。ひとり事業では、**稼働を埋め切らないこと自体が戦略**である。

### 8-6. 週次で追うKPI（先行指標だけ）

売上や成約数は**遅行指標**で、見ても手遅れ。ひとりで毎週追うのは**自分が今日コントロールできる3つ**に絞る。

| 指標 | 週次目標 | なぜ |
|---|---|---|
| **提携先へのアプローチ件数** | **2件/週** | 最大の律速（§8-3）。ここが止まると1年後に効く |
| セミナー申込数 | 4社/週 | 集客の唯一の自社チャネル |
| **デリバリー実績時間の記録** | 毎週必ず記録 | 測らないと必ず超過する。**記録すること自体がKPI** |

### 8-7. 警戒ライン（この数字を割ったら設計を疑う）

| 指標 | 警戒ライン | 取るべき行動 |
|---|---|---|
| 診断→コホート転換率 | **30%を下回る** | 診断の設計か、コホートの中身を作り直す |
| コミュニティ月次解約率 | **5%を超える** | 提供価値の見直し。会員数を追うのをやめる |
| デリバリー稼働 | **月100hを超える** | **値上げするか、受注を断る**（増やす選択肢はない） |
| 顧客の成約率改善 | **2期連続で+5pt未満** | 商品の根本的な作り直し。売るのを一旦止める |

**最重要KPIは2つ。**
1. **顧客の成約率改善** — 出れば全てが回り、出なければ何をしても続かない
2. **デリバリー時間 月100h以内** — 超えたら値上げするか受注を断る。**ひとりの事業では、忙しさは成功ではなく設計ミスのサイン**

## 9. 検証プラン（Go / No-Go）

いきなり全面展開せず、**90日で潰す**。「テーマ決め→商品づくり→集客→セールスまで一人で3〜4ヶ月回してみる」という定石に沿う。

| フェーズ | 期間 | やること | Go条件 |
|---|---|---|---|
| **Phase 0** | 〜30日 | リフォーム会社20社にヒアリング（無料診断を口実に／**プラットフォームで相談を受ける側に登録して集めてもよい**）。並行してFC本部・メーカー3社＋**地銀・信金の本業支援部署2行**にアポ | 「営業の成約率が課題」と答える社が10社以上 |
| **Phase 1** | 〜60日 | **有料診断（20万）を5社に提案** | **3社が実際に金を払う** ←本当の判定ライン |
| **Phase 2** | 〜90日 | うち2〜4社で**第1期コホートを実施**（初回は定員割れでも走らせる。事例が目的） | 1社で成約率+10pt を実測 |
| **Phase 3** | 〜180日 | 事例を武器にセミナー開始＋提携交渉 | 第2期が4社以上で埋まる／提携1社成立 |

**No-Go判定：** Phase 1で有料診断が1社も売れなければ、業種を第2候補（自費診療クリニック／外構）に切り替える。事業を畳むのではなく、**業種を差し替えて同じ型を試す**。これが1業種特化戦略の利点。

**ひとりだからこその判断基準：** Phase 2 で「これは訪問しないと成果が出ない」と分かった場合、**事業を止める**。訪問必須なら §1-2 の通り年商1,920万で頭打ちになり、ひとりで背負うリスクに見合わない。

## 10. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| **【最大】自分が倒れたら売上ゼロ** | 特大 | ①所得補償保険・就業不能保険に加入 ②コホートは動画教材化して**延期可能な設計**にする ③コミュニティは月1回開催なので1回飛ばしても崩れない ④現金6ヶ月分を常に確保 |
| **稼働の天井にぶつかる** | 大 | 月100hを超えたら**値上げか受注制限**。売上のために時間を売り始めた時点で事業モデルが崩壊する |
| **集客と提供の同時進行ができない**（ひとりの典型的な失敗） | 大 | コホート型で提供を期間集中させ、**提供のない月を営業月にする**。年4期＝提供と集客を交互に回す |
| **顧客に払う体力がない**（BtoCの価格転嫁力の低さ） | 大 | コミュニティ（月4万）を受け皿に。補助金活用で実質負担を圧縮 |
| **船井総研等の大手と競合** | 大 | 正面衝突を避け、年商1〜5億の「大手のターゲット外」を狙う |
| **成果が出ない**（営業改善は顧客の実行力に依存） | 大 | コホートの**同期プレッシャー**を活用（他社が実行していると自社もやる）。コホート型の高い修了率はこの効果による。実行しない顧客とは契約しない基準を持つ |
| **提携先への依存** | 中 | 1提携先の売上構成比を40%以内に。3年目までに提携先3社を確保（上振れを狙うなら6社） |
| **属人化して売れない／引き継げない** | 中 | 1期目から全プロセスを動画・ドキュメント化。将来の外部講師化・ライセンス化の布石にもなる |
| **特商法等の規制**（訪問販売業種のため） | 中 | クーリングオフ・不当勧誘の遵守を型に組み込む。**「売り込み強化」ではなく「顧客理解の型化」として設計する**（コンプライアンス面でも成果面でも正しい） |
| **AI代替**（営業ノウハウの汎用化） | 中 | AIを敵に回さず武器にする（商談解析）。実行支援＝人がやる部分に価値を寄せる |

## 11. 総括：5行で

1. **需要はある。ただし"潜在需要"である** — 「営業を教えてほしい」と探している社長はほぼいない。しかし「問い合わせは来るのに契約にならない」痛みは全社が抱えている。**売るのは営業指導ではなく"成約率"。** 人手不足倒産が過去最多で増員による解決が塞がれた今、この需要は構造的に強まる。
2. **ただし汎用の「中小企業向けtoC営業コンサル」では負ける** — 船井総研が押さえており、toC中小企業は価格転嫁力が低く原資が薄い。**1業種特化でしか勝てない。**
3. **社長ひとりなら、1対1の訪問型は絶対に選んではいけない** — 年商1,920万で頭打ちになり、新規営業の時間も残らない。**コホート型（6社同時）＋会員制コミュニティ**が唯一の解。
4. **単価は上げられる。ただし"実績と引き換えに、顧客サイズ別に"** — 均一120万は大口顧客から取り損ねている。同じ講義に座っても顧客が得る額は会社規模で3倍違う（450万 vs 1,350万）。サイズ別価格の導入だけで**追加工数ゼロのまま平均単価が+50〜90%**。ただし**1年目は上げない**——事例がゼロの状態で値上げは通らない。
5. **KGIは3年目 年商4,830万・社長の取り分3,810万・稼働月100h以内・顧客の8割で成約率+10pt** — 当初は年商1.1億を標準に置いていたが、**船井総研の1人あたり売上1,600万の6.9倍**にあたり楽観と判断、**上振れケースに格下げした**（→§8-1）。保守ケース2,400万でも成立する下振れ耐性がある。最大の急所は**提携先3社**（コホートの半分を提携で埋める前提が崩れると成立しない）。まずリフォーム業界で、**90日・有料診断3社**を売れるかで判定する。

> **ひとり事業の本質：追うべきは売上規模ではなく利益率。** 船井総研の純利益率10.5%に対し、本事業は経費率21%＝**取り分率79%**。年商4,830万・取り分3,810万のひとり社長は、年商5億の会社の社長より手取りで勝ちうる。**だから規模を追う必要がない。**
