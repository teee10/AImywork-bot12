# ひねり飛車 完全入門（解説動画）

初心者から将棋ウォーズ1級を目指す人向けの、ひねり飛車の解説動画です。

- `hineri_bisha.mp4` … 完成動画（1280x720、約8分30秒、日本語ナレーション付き、全30シーン）
- `make_video.py` … 動画生成スクリプト（盤面描画・音声合成・エンコード）

## 内容

1. ひねり飛車ってどんな戦法？（符号の読み方 / 居飛車と振り飛車 / 使える場面）
2. 基本定跡（相掛かり → ▲2六飛 浮き飛車 → ▲3六飛 縦歩取り → △3三金 → ▲7六飛）
3. 玉の囲い方（坊主美濃 → ▲2七歩で片美濃）
4. 攻めの手筋（▲7四歩 △同歩 ▲同飛 の歩交換 ほか）
5. 後手の対策 △8四飛
6. よくある失敗と1級への練習法・まとめ

## 再生成

```bash
pip install python-shogi pyopenjtalk-plus pillow numpy   # ffmpeg も必要
python3 videos/hineri-bisha/make_video.py
```

指し手はすべて python-shogi で合法手チェックしています。
